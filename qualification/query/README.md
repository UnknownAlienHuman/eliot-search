# W4 query qualification

This directory defines the P08/G2 product-slice evidence contract for request admission, planning,
bounded execution, source-backed validation, compact projection, opaque handles and continuations.

- [`W4_QUALIFICATION.md`](W4_QUALIFICATION.md) — ownership, execution order, stop conditions and evidence.
- [`baseline.toml`](baseline.toml) — designed baseline profiles and architecture ceilings; not an accepted runtime configuration.
- [`probes.toml`](probes.toml) — machine-readable mandatory probes, initially `UNAVAILABLE`.

These files do not authorize W4 implementation and do not constitute passing evidence. W4 remains
blocked until accepted W0–W3 handoffs and launch-state advancement.
