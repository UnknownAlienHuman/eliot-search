# Execution evidence

Checks belong to the exact GitHub Actions run/PR and the [current registry](../docs/audit/ANALYSIS_REGISTRY.md#evidence-status).
There is no checked-in approval, receipt, wave or qualification database. Compiler success does not prove runtime behavior.

The [removed reports](https://github.com/UnknownAlienHuman/eliot-search/tree/f3d710131aa3b06a63198694bed7ec82b1e251df/qualification) remain immutable history, not implementation requirements.
Keep local transcripts out of Git; retain only a concise reproducible finding and a link to its raw run.
