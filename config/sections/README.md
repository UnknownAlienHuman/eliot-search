# Configuration section packet disposition

A section file documents source reality or the selected replacement. It does not register a setting. The
machine registry and wave metadata are historical removal inputs.

## Consolidate into concrete typed settings

- `instance` → actual data root and any genuinely supported process mode;
- source admission/reader/reconcile → source roots, policy and acquisition limits actually consumed;
- revision store/secrets → selected storage profile and concrete owner limits/credential inputs;
- lexical → one published retrieval profile;
- Qdrant process/data → one endpoint profile and optional real managed child;
- query/handles/continuations → direct query defaults and one temporary `QueryWindow`.

## Remove until a real consumer exists

- generic control migration configuration;
- generic scheduler;
- generic index reclaimer/retention platform;
- overlay settings without an editor integration;
- observability settings without an actual logger owner;
- optional capability toggles without a selected extractor/model/handler.

No packet requires `section_descriptor`, digest, reload decision, `ConfigApplyReceipt`, wave gate or accepted
capability. #333 owns the typed cutover; #214/#525 remove registry/tooling consumers.
