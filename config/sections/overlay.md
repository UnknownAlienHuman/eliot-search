# Editor overlay settings disposition

`[overlay]` is not registered by the current daemon and the existing overlay package is disconnected. Delete
the generic persistent/TTL/revision platform unless a real editor integration selects the thin memory-only
map under #336.

A future overlay accepts bounded unsaved bytes from that integration, keeps them process-local, narrows to the
same source/scope/evidence rules and disappears on disconnect/restart. It does not become a second index or
source authority.

No public overlay settings, section descriptor or reload receipt exists before that consumer.
