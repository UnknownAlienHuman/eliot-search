# W5 current-workspace contract pack

This directory is the bounded implementation projection for observation continuity, saved/unsaved
workspace overlays and Rust syntax enrichment in ELIOT Search 8.4. It does not authorize W5
implementation and does not replace Architecture Part I.

Ordinary W5 writers read only:

1. root/family/package `AGENTS.md`;
2. their package assignment and package-local `FUNCTIONS.md`;
3. relevant sections of [`W5_CURRENT_WORKSPACE_CONTRACTS_1.0.md`](W5_CURRENT_WORKSPACE_CONTRACTS_1.0.md);
4. the W5 settings packet where applicable;
5. accepted direct-dependency API handoffs and package-local fixtures.

The pack covers:

- watcher hints, overflow/gap state and authoritative bounded inventory reconciliation;
- truthful observation/workspace/projection currentness;
- saved-revision overlays while background publication catches up;
- explicit unsaved buffer snapshots scoped to one binding/workspace;
- shadowing stale base points before retrieval and IDF;
- memory-only unsaved preparation/retrieval and deterministic invalidation;
- qualified Rust syntax enrichment without builds, hooks, macros or compiler certainty;
- exact source/revision/unit/anchor identity across all transient products.

Machine inventory: [`manifest.toml`](manifest.toml).

No file here permits a watcher event to prove currentness, persists unsaved bytes, turns an overlay into a
second database or claims compiler-semantic certainty from syntax parsing. W5 remains blocked until
accepted G2/W4 integration evidence and direct dependency handoffs exist.
