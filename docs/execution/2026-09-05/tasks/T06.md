## Required change

- Use one bounded framing contract in shell/service/proxy; oversized or truncated frames close the session without draining an unlimited suffix.
- Add finite startup/request/drain/child-exit deadlines, response bytes and queue ceilings. A socket timeout is not a child-execution deadline.
- Preserve the existing non-reusable-channel fence: no next client receives previous stdout and no mutation is auto-replayed after connection loss.
- Replace terminal-event substring guesses with validated versioned frame boundaries/request IDs where the current protocol permits; T19 supplies canonical provider envelopes.

## Discriminating tests

- Real socket disconnect midway through a large response, then reconnect/health; no old line reaches the new request.
- Child hangs before READY, mid-response and at shutdown; timeout terminates/reaps it without indefinite pipe writes.
- Oversized unterminated input, CRLF boundaries, invalid UTF-8, slow reader, EOF and ordinary complete command error.
