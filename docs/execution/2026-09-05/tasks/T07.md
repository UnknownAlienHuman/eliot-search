## Required change

- Construct a platform adapter that proves final object/ancestor containment and policy before bytes are admitted, then call the shared safe-reader kernel.
- Reject symlinks, reparse points, device/pipe objects, path escape, unsupported identity and ACL violations according to the qualified profile. Handle root relocation explicitly.
- Apply finite bytes/retries/cancellation before allocation and during reads; compare relevant final-handle state after reading.
- Keep relative path tokens and errors redacted; do not print RelativePathToken raw content in Debug. Never execute source hooks/scripts/macros.

## Discriminating tests

- Deterministic replacement between precheck/open, ancestor rename/junction, hardlink outside domain, in-root rename, access revocation during read.
- Zero/oversized/truncated/changed source and cancellation; no bad bytes reach revision admission.
- Native Windows tests plus Linux non-platform conformance, with each unsupported capability denied.
