# Working on the daemon

The daemon owns native invocation/bootstrap, root operations, retain-file, prepare-source and publish-prepared. Preserve the existing child, root guard and original deadline. Follow [FUNCTIONS.md](FUNCTIONS.md): full object/backend verification and independent canary precede short current CAS; complete matching RO snapshot validation precedes publication output.

Keep selected settings, whole units and per-operation output caps. Never reopen live sources, rebuild missing/corrupt Ready artifacts, skip evidence validation for zero-hit queries or replace the canary with a user query. Only the bridge uses SDK types; the operator owns Qdrant startup/storage. Retain unresolved target obligations. No legacy admission/replay/qualification platform or temporary transport.
