# Optional local adapter — not a second session system

The inspected old adapter duplicates binding, replay, terminal receipt and drain state. Do not connect it merely
to preserve an existing package. The same-account client/protocol owns sessions; remote users and authentication
are outside [local scope](../../docs/architecture/LOCAL_SCOPE.md).

## Current installed and donor state

[Prior exact donor/caller readset](https://github.com/UnknownAlienHuman/eliot-search/blob/6ae24197a1be8695ede5bb7d12dfaf97f5bca1fc/crates/search-eliot-adapter/README.md)
is historical evidence, not a current SDK-version promise. No SDK is adopted by this documentation change.
Recheck manifests, callers and the official SDK API/version/features only when a real adapter consumer is selected.

## Optional target after baseline Search works

One small stdio tools adapter may map working Search/Exact/Continue/Expand operations to the same local client.
Use the maintained SDK rather than another protocol implementation. Keep arguments/results finite and preserve
source-backed semantics, cancellation, EOF cleanup and window/session lifetime. Do not expose raw filesystem,
Qdrant, redb, shell, network or arbitrary recipe/filter tools. No HTTP/OAuth/remote or generic integration platform.

## Removal boundary

Trace actual callers before deleting the old adapter ledger, replay/MAC/grant types, receipts and exclusive
fixtures. Keep any useful typed mapping beside its consumer; do not retain a forwarding crate or create an
adapter requirement for baseline Search. [FUNCTIONS.md](FUNCTIONS.md) retains the source-removal seams.

## Completion

The optional adapter works only after the underlying local operations work. Check the actual adapter/client
closure after code; broad tests remain later. [Working guide](../../docs/implementation/WORKING_GUIDE.md) owns checks
and update steps. No adapter behavior is delivered by this page.
