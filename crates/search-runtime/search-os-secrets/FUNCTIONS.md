# Plain-storage boundary

The unused secret lifecycle, revision-envelope and DEK-selection Rust package, manifest and exclusive
fixtures are removed. The selected product uses plain local objects and owned-child communication.

No application key service, encrypted-record catalogue, secret lease, pairing or key migration is needed
for search. Unsupported protected data stays unsupported and unchanged. Preserve user files, existing keys
and unpublished work; deleting obsolete repository code never authorizes deleting credentials or user data.
An existing optional Qdrant API key is consumed directly by the actual bridge configuration.
