# Historical optional evaluation programme

The old W10 programme described provider-style evaluation, immutable evidence ledgers, qualification
receipts, review authority and Product Pulse acceptance. It is not a current implementation requirement.

Current evaluation is optional post-product tooling:

```text
explicit finite cases/qrels
+ actual public CLI results
+ raw durations/selected counters
→ standard deterministic metrics and descriptive summary
```

The evaluator does not own source admission, query/ranking behavior, release authority or product readiness.
It does not feed hidden learning/tuning into production. Failed/partial/not-run cases remain visible.

Do not implement W10 capability/provider registries, evidence ledgers, canonical run identities, attestation,
reviewer quorum or runtime acceptance tokens. Release qualification is the focused human-readable process in
[#215](https://github.com/UnknownAlienHuman/eliot-search/issues/215), after #264 proves the connected product.

requires it.
