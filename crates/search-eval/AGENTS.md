# Working on search-eval

This package is optional post-product tooling. Read [README.md](README.md), [FUNCTIONS.md](FUNCTIONS.md) and
release issue [#215](https://github.com/UnknownAlienHuman/eliot-search/issues/215).

Do not add canonical run/evidence identities, immutable run stores, receipt/verdict/reviewer authority,
in-toto/DSSE, recursive verifiers, process/fault/disclosure frameworks or product dependencies.

After the connected product exists, keep only small pure operations over explicit finite case/qrel/result
files: validation, standard relevance metrics, status counts, raw-duration summaries and compatible-run diff.
Every declared case remains visible, including failure/partial/timeout/cancel/not-run. Reports are descriptive,
not runtime credentials or release authorization.

A release runner uses the public CLI/protocol and records raw rows. It can remain a small existing tooling
command/script; do not create a general runner package unless a concrete measured need justifies it.

Delete the current audit/evidence/receipt/review/SLO/fingerprint modules and fixtures which no selected #215
workflow uses. If no real release consumer needs the remaining Rust library, delete this package entirely.

After production/tooling code, run minimal Rust 1.98 compiler/Clippy for the changed evaluator/tool and focused
hand-computable metrics/file-bound cases. Product runtime and implementation PRs do not depend on this crate.
