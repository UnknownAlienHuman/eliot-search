# Operator-owned Qdrant

The unused Qdrant supervisor Rust package, manifest and exclusive fixtures are removed.
The operator starts/stops the same-host service. ELIOT owns requests and its collections.

The concrete bridge receives the loopback endpoint, optional existing API key and original execution limits.
Keep actual SDK schema/readback, bounded RPCs and typed failures. A connection requires no launch receipt,
executable qualification, credential lease, containment record or process adoption.
Never kill the independently operated server or introduce transport/profile fallbacks.
