# Generation-bound point identity

The unused legacy/S11 identity Rust package, manifest and exclusive fixtures are removed.
Current publication derives its point identities in the concrete CONTROL publication owner.

Physical generation names are never reused. Within a generation, deterministic point addresses bind
the actual source/prepared unit identity and exact evidence range. The address is a locator;
saved full binding and readback reject a conflicting meaning.
Equal text in distinct occurrences does not merge evidence.

Complete-generation publication needs no cross-generation continuity, mutable point registry,
occurrence-incarnation platform, dual minting or compatibility migration.
