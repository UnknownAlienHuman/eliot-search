# Working on preparation

Read the [task map](README.md), then the affected owner's FUNCTIONS.md and actual callers. Follow the root
working guide; do not reload the architecture or every format recipe for one change.

Implement the selected format through one retained read, one materialization and one unitization. Pass the owned
product directly; no reparse, second object writer, pipeline registry or public proof types between these steps.

prerequisite catalogue. Move real consumers and remove displaced code together; preserve user data/private work.
