# Concrete owner calls

The unused ports catalogue Rust package, manifest and exclusive fixtures are removed.
The product calls its concrete CONTROL, source/object, preparation, bridge and child owners directly.

Pass original execution deadline/cancellation and operation-specific bounds. Keep effect uncertainty
with its real owner: exact row readback, object verification, backend observation or owned-child wait.
A narrow standard-library/local interface is justified by actual ownership or implementation variation,
not by a future noun. No ports-v2 catalogue, universal context, conformance registry or dummy adapter.
