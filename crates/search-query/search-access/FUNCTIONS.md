# Local source selection

The unused access/grant/barrier Rust package, manifest and exclusive fixtures are removed.
This policy applies when a real selection consumer is connected beside the query owner.

Omitted selection uses the configured default; explicit empty stays empty and performs no RPC.
Resolve membership from the pinned published inventory. Unknown, foreign or incomplete membership never
widens to all sources. No authentication, grant, revocation or security-generation system is selected.

## Candidate and statistics scope

Base population is the selected sources. Candidate-only path/kind/text narrowing intersects that base;
IDF still uses the base. A whole-collection base omits only redundant base/IDF clauses, preserving
request-only narrowing. Use a filter field only with its actual indexed producer.
Incompatible score populations are not sorted together.

A current source edit affects new requests. An existing session window keeps its original view and
selection. Exact and evidence reads use the same selected inventory.
