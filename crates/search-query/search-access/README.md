# Local source selection

Select sources inside one pinned published view; do not create grants, users or a permission platform.
[FUNCTIONS.md](FUNCTIONS.md) owns default/empty/unknown selection, candidate filters and IDF population.
[Local scope](../../../docs/architecture/LOCAL_SCOPE.md) defines the one-account boundary.

Move the small resolver to its actual query consumer if no substantial package remains. Legacy access/barrier
code still requires caller cutover; this page does not claim it has been removed.
