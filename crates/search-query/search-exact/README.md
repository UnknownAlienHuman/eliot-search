# search-exact

**C20 — frozen-denominator exact verification.**

**Status:** substantive source exists for exact-proof state, literal execution and a vendor-neutral exact
spine. The complete authoritative denominator, source adapters and public daemon/CLI product path are not
yet qualified.

## Owns

- exact predicate and completeness semantics;
- frozen denominator identity and validation;
- bounded literal/regex/symbol/structural execution mechanics as accepted profiles are added;
- scanned item/byte accounting;
- changed, unreadable, denied, timed-out and cancelled dispositions;
- the rule that complete negative conclusions require every denominator item;
- deterministic proof/report identities.

## Must not own

- candidate top-k as a completeness denominator;
- Qdrant/redb/filesystem vendor clients;
- source authorization or scope widening;
- semantic absence claims from lexical similarity;
- hidden durable query history;
- unbounded scans.

## Current gap

The package is `SOURCE`. It becomes product evidence only when the daemon freezes an authoritative eligible
source/revision denominator, executes exact retained-source reads, records truthful coverage and exposes
the typed report through the public recipe path. Top-k saturation, grep over a guessed directory or a
successful unit test is not an accepted complete proof.
